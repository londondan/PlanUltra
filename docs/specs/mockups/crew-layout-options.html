Crew station card — layout options

Four options for fitting the QR code more compactly. Option D is the newest — QR spanning both header and location strip as a flush-right column.

Option D — Spanning QR sidebar (header + location strip)
D Spanning QR sidebar
The QR code lives in a dedicated right-side column that spans from the top of the station header all the way to the bottom of the location strip — the full height of both rows. The header content and location block each use the remaining left/center width. No QR in either row independently; it occupies its own vertical slice.
ProsQR is larger and more scannable · clean visual separation · header stays single-row · location strip stays uncluttered · feels intentional rather than crammed in
ConsSlightly more complex CSS (requires a wrapper with grid or relative positioning) · the QR column is always present even when there's no location note
QR at 80–90px · same total vertical height as Option A but better use of horizontal space

Option A — Inline strip (current direction, tightened)
A Compact inline strip
Directions button, QR code, and location notes all sit in a single tight horizontal row. QR shrinks to 56×56px and floats right. The whole location block is one dense strip — minimal vertical height.
ProsSingle-line height · clean · prints very short
ConsQR at 56px may be tight to scan · notes get narrow if long
~1.1" tall location block on print

Option B — QR in header row
B QR tucked into header
The QR code lives in the station header row, right-aligned, replacing the ETA's position (ETA moves to the second line). The location block below has only the directions button and notes — no QR column. Header gets slightly taller but the location block shrinks dramatically.
ProsLocation block is now just one line · QR is immediately visible · saves the most vertical space overall
ConsHeader is a bit busier · QR at 52px in header may feel cramped
~0.7" tall location block on print · saves most vertical space

Option C — Print-only QR (hidden on screen)
C Print-only QR
On screen, the QR is completely hidden — just the directions button and notes are shown. On print, the QR appears in a compact right column. Screen view is cleanest; printed page is compact and functional.
ProsCleanest screen layout · no wasted space on screen · print version still scannable · most vertically efficient
ConsCrew can't scan from screen — they must print or use the directions button. Relies on crew printing the sheet, which is the stated intent.
QR hidden on screen — shown only on @media print in a compact right column
