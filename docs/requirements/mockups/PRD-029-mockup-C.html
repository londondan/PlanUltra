Design C — Stacked sub-label. The visit ordinal appears on a second line directly beneath the station name — VISIT 1 OF 2 in a small uppercase monospace style at 65% Ridge Blue opacity. The station name stays on its own line, clean and uncluttered. The sub-label reads almost like a subtitle or context cue. Benefit: the station name is completely unambiguous on its own line; the ordinal is clearly secondary contextual info rather than part of the name. Works especially well when the station name is long. Trade-off: adds a small amount of vertical height to cards that have duplicates, which could push the printed layout slightly longer. Unique stations have no added height — only duplicate cards grow.
