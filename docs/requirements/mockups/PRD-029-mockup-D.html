Design D — Coloured visit indicator. A coloured left-border accent (green for first visit, amber for second) and a small "1st visit" / "2nd visit" corner badge distinguish repeated stations. The station name itself is not modified — it stays as "Twin Lakes" with no appended suffix. A mini legend at the top of the station list explains the colour coding once. Benefit: the most visually immediate of the four approaches — crew can spot a repeated station by colour before reading a word. Works well when the printed sheet is scanned quickly. Trade-offs: (1) relies on colour, which fails in greyscale printing — a fallback pattern or border weight change would be needed for print; (2) introduces a new UI element (the colour system + legend) with its own cognitive overhead; (3) the segment line still uses the plain name "Twin Lakes → Hope Pass" with no ordinal, which could re-introduce ambiguity in cross-reference. Does not modify the station name string, so it does not affect the disambiguateStationNames utility used in other surfaces (aid station table, etc.).
