PRD-030 — Crew sheet print mockup
Same data as the attached Grindstone 100 sample (7 crew stations, 18 aid stations). The two sheets below are sized to actual US Letter dimensions (8.5×11in) so what you see is what would print. The current production print output runs 4 pages for this exact race. This layout was verified with a real headless-Chromium print-to-PDF render — the split below matches where the browser actually breaks the page, not a guess.
What changed from the current print output: (1) Header and label text is now solid, opaque color — nothing depends on a dark background rendering, since browsers commonly print with "background graphics" switched off, which is very likely why the current header prints washed-out. (2) Card padding, font sizes, and line-height are tightened for paper, not touch targets, and the redundant "✓ Crew access" badge is dropped from station cards — every card in this timeline is a crew station by definition, so the badge said nothing the mile pill and QR sidebar didn't already imply. (3) Intermediate checkpoints keep their one-row-per-checkpoint layout (per feedback — this is useful information crew members read at a glance) but the rows themselves are tightened to the same print scale as everything else. ETA, QR codes, directions, and location notes are all still present.
