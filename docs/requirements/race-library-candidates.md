# Race Library — Candidate Races
**Created:** 2026-03-23
**Purpose:** Proposed starting set for the PlanUltra race library (PRD-012). These are races that would give users a meaningful, high-quality set of templates to start from. GPX files will need to be sourced separately for each.

---

## Curation Criteria

Races were selected for:
- **Name recognition** — races a runner is likely to be training for
- **Geographic diversity** — spread across US regions + international
- **Distance variety** — 50K through 200+ miles
- **Aid station richness** — races with well-defined crew/drop bag points make for better templates
- **Crew-access variety** — wilderness races (Hardrock, Barkley) are useful precisely because crew access is limited

## GPX Sourcing Notes

Official GPX files are available for most of these races directly from their websites or from the UTMB World Series index. For races without an official GPX (e.g. Barkley), a community-sourced file from Strava or Garmin Connect is typically available — flag these as "unofficial route" in the library description.

> Races with restricted or unavailable GPX files should be noted in the admin UI with a `gpxSource: 'unofficial'` flag so users are aware.
